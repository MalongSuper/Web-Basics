# Web Basics

A collection of **HTML, CSS, and JavaScript examples** created for learning and practicing the fundamentals of web development.

This repository focuses on small, practical examples that demonstrate how the three core technologies of the web work together:

* **HTML** — Structure and content
* **CSS** — Styling and presentation
* **JavaScript** — Behavior and interaction

The examples are designed to build a solid foundation for creating interactive web pages and understanding how frontend development works.

## HTML

Examples cover common web page elements and concepts such as:

* Page structure
* Headings and paragraphs
* Links and images
* Lists and tables
* Forms and user input
* Semantic elements
* Multimedia
* HTML attributes

## CSS

Examples demonstrate how to control the appearance and layout of web pages, including:

* Colors and typography
* Spacing and sizing
* Borders and backgrounds
* Selectors
* Box model
* Flexbox
* Grid
* Positioning
* Responsive design
* Transitions and simple animations

## JavaScript

Examples demonstrate how JavaScript can make web pages interactive, including:

* Variables and data
* Conditions and loops
* Functions
* Arrays and objects
* Events
* DOM manipulation
* Form handling
* Dynamic content
* Simple interactions

## HTML + CSS + JavaScript

The repository also contains examples that combine the three technologies to demonstrate the relationship between:

**HTML → Structure**
**CSS → Presentation**
**JavaScript → Behavior**

> **Build the page. Style the page. Make it interactive.**
